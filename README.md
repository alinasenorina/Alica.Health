# Алиса.Здоровье — Интеллектуальный ассистент онлайн-консалтинга

### 1. Какую проблему решает проект?

Мы решаем проблему **«неэффективного первичного контакта»** в медицине. Проблема разделена на три уровня:

*   **Для врача (Бюрократическая нагрузка):** Врачи тратят до **40% времени приема** на рутинный сбор анамнеза и ручной ввод данных в карту. На глубокую диагностику и общение с пациентом остается катастрофически мало времени. 
*   **Для пациента (Трудности самодиагностики):** Пациенты часто не могут четко сформулировать жалобы («где-то покалывает») и записываются не к тем специалистам. Это приводит к потере времени на «пустые» консультации и лишним тратам.
*   **Для клиники (Операционные потери):** Неструктурированные данные и ошибки в навигации пациентов снижают пропускную способность клиники и лояльность клиентов. Данные в картах часто не стандартизированы (отсутствие кодов МКБ-10 в первичном описании).

## Решение
**Алиса.Здоровье** — это бесшовный мост между первым симптомом и врачебным заключением. 
1. **AI-Анамнез:** Алиса опрашивает пациента, используя медицинские протоколы.
2. **RAG-симуляция:** Система сопоставляет жалобы с базой знаний МКБ-10 и генетическими рисками в реальном времени.
3. **Smart Routing:** На основе собранных данных ИИ рекомендует конкретного специалиста из клиники.
4. **Auto-Report:** Врач получает готовую форму 025/у (анамнез), заполненную ИИ на медицинском языке и рекомендации Алисы на основе RAG.

Cписок основных возможностей:

### 1. Интеллектуальный сбор анамнеза (Patient Interviewing)
Алиса ведет естественный диалог с пользователем, имитируя опрос реального врача.
*   **Удержание контекста:** Она помнит предыдущие ответы и задает уточняющие вопросы в строгом медицинском порядке (жалоба → длительность → характер боли → сопутствующие факторы).
*   **Контроль логики:** Алиса не просто переписывается, она извлекает структурированные данные из разговора для заполнения медицинских карт.

### 2. Маппинг в формат МКБ-10 (Medical Classification)
Алиса выступает как экспертная система классификации.
*   **Автоматическое кодирование:** На основе описанных симптомов (например, «боли в пояснице») она подбирает соответствующий код в международном классификаторе болезней (например, `M54.5`).
*   **Предварительная диагностика:** Формирует гипотезу о заболевании, которую врачу остается только подтвердить или опровергнуть.

### 3. Верификация знаний через RAG (Retrieval-Augmented Generation)
Это ключевая фишка для безопасности — Алиса не «галлюцинирует», а опирается на базу данных.
*   **Проверка совместимости:** При упоминании лекарств Алиса через векторный поиск проверяет их взаимодействия (например, синергия Магния и Мелатонина или запрет на Алкоголь).
*   **Доказательный подход:** Ответы ИИ дополняются выжимками из проверенных клинических руководств, загруженных в систему.

### 4. Мультимодальность: Распознавание речи (Speech-to-Text)
Благодаря интеграции со **SpeechKit**, Алиса умеет «слышать».
*   **Транскрибация консультаций:** Пациент или врач могут загрузить аудиозапись разговора (в форматах MP3, OGG, WAV), и Алиса мгновенно превратит её в текст.
*   **Работа с терминологией:** Модель настроена на распознавание сложной медицинской лексики и названий препаратов.

### 5. Автоматизация документооборота (Auto-reporting)
Алиса берет на себя самую скучную часть работы врача — заполнение бумаг.
*   **Формирование формы № 025/у:** Из текста консультации Алиса автоматически вычленяет жалобы, анамнез и назначения, расставляя их по нужным полям официального медицинского бланка.
*   **Саммаризация:** Превращает длинный разговор в краткий и емкий медицинский отчет.

### 6. Маршрутизация пациента (Specialist Matching)
Алиса работает как интеллектуальный диспетчер.
*   **Подбор специалиста:** Анализируя тяжесть и специфику симптомов, она определяет, к кому именно нужно направить пациента (дерматолог, невролог, кардиолог и т.д.).
*   **Интеграция с агрегаторами:** На основе вердикта Алисы система предлагает реальных врачей с порталов (например, ProDoctorov).

## Технологический стэк проекта

#### **Frontend (Client Side)**
*   **HTML5 & CSS3:** Адаптивная верстка с использованием **CSS Grid** и **Flexbox**. Реализована сложная анимация (pulse, bounce, typing indicators) и кастомные UI-компоненты.
*   **Vanilla JavaScript (ES6+):** Весь фронтенд написан на чистом JS без тяжелых фреймворков (React/Vue), что обеспечивает мгновенную загрузку.
*   **Fetch API:** Для асинхронного взаимодействия с бэкендом.
*   **Web Audio & Drag-and-Drop API:** Для загрузки и обработки аудиофайлов консультаций.
*   **Print-to-PDF Engine:** Использование CSS-директив `@media print` для генерации медицинских отчетов по форме № 025/у прямо из браузера.

#### **Backend (Server Side)**
*   **Node.js:** Среда выполнения серверного JavaScript.
*   **Native HTTP/HTTPS Modules:** Сервер реализован без использования сторонних фреймворков (типа Express), что минимизирует количество зависимостей и повышает безопасность.
*   **Dotenv:** Управление конфигурацией и безопасное хранение API-ключей через переменные окружения.
*   **CORS (Cross-Origin Resource Sharing):** Настроен для безопасного взаимодействия между фронтендом и API-шлюзом.

#### **AI & Machine Learning (Yandex Cloud)**
*   **YandexGPT (Model: yandexgpt/latest):** Основной интеллект системы для сбора анамнеза, классификации диагнозов и генерации рекомендаций.
*   **Yandex SpeechKit (STT):** Преобразование речи пациента в текст (поддержка форматов MP3, OGG, WAV).
*   **Yandex Text Embeddings:** Генерация векторных представлений текста для работы RAG-системы.

#### **RAG & Архитектура данных (Retrieval-Augmented Generation)**
*   **Vector Database (In-Memory):** Реализована легковесная векторная база знаний прямо в оперативной памяти сервера.
*   **Cosine Similarity Algorithm:** Математический алгоритм для поиска семантического сходства между запросом пользователя и базой медицинских знаний.
*   **Context Injection:** Метод динамической подмены системного промпта для минимизации галлюцинаций ИИ.

## Структура проекта
*   `server.js` — бэкенд на Node.js. Выполняет роль прокси для работы с Yandex Cloud API, реализует RAG-логику и хранит системные промпты.
*   `alica-health-ai.html` — одностраничное приложение (SPA) с интерфейсом чата, динамическими карточками анамнеза и модулем видеоконсультации.

## Запуск проекта
```
проект/
├── .html      # (бывший genotek-health-ai (2).html)
├── .env                # Файл с ключами
├── server.js           # сам сервер
├── package.json        # Файл зависимостей
└── README.md           # Инструкция
```
## Шаг 1. Установка среды
Для запуска сервера необходима среда **Node.js**. 
1. Перейдите на официальный сайт: [https://nodejs.org/](https://nodejs.org/)
2. Скачайте и установите версию **LTS** (рекомендуется для всех). 
3. При установке просто нажимайте "Далее" (Next).

## Шаг 2. Настройка ключей доступа
В консоли напишите git clone [ссылка с гитхаба на проект]
В корне папки проекта создайте файл с названием `.env` и вставьте туда данные для доступа к Yandex Cloud:
```text
YANDEX_API_KEY=ваш_ключ
FOLDER_ID=ваш_id_каталога
```
*Без этих ключей функции ИИ (YandexGPT и SpeechKit) будут недоступны.*

## Шаг 3. Установка библиотек и запуск
1. Откройте терминал (командную строку) в папке проекта.
2. Введите команду для установки необходимых модулей:
   ```bash
   npm install
   ```
3. Запустите сервер:
   ```bash
   node server.js
   ```

## Шаг 4. Просмотр результата
После появления сообщения `Сервер запущен: http://localhost:3000`:
1. Откройте любой браузер.
2. Перейдите по адресу: **http://localhost:3000**
3. **ВАЖНО:** Не открывайте файл `.html` двойным кликом из папки. Используйте именно адрес `http://localhost:3000`, чтобы фронтенд мог общаться с бэкендом.

## Перспективы развития
*   **RAG:** Загрузка полных PDF-клинических рекомендаций Минздрава в Yandex Search Query для сверхточной диагностики.
*   **Контекст:** Прямая интеграция с API личного кабинета клиента для учета его истории болезней.
*   **OCR:** Модуль распознавания старых анализов пациента и их суммаризация.
*   **Календарь:** Напоминание пациента употребить лекарства или о записи к врачу
*   **Аналитика:** Аналитика для клиниик и интеграция с медицинскими агрегаторами (b2b потенциал)
